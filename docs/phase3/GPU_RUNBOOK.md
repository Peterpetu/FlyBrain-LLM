# Phase 3 GPU runbook: how every GPU result was produced, and how to reproduce it

*Every command runs from the repository root. This file replaces the pre-run runbook of September
2026; the history of the design (three versions of rung 1, two of rung 1b, and why) is in
docs/phase3/EXPERIMENT_PLAN.md. Two modes never touch a pre-registration: `--smoke` (toy size) and
`--probe` (real size); both write to a scratch directory (`$SCRATCH`). The first plain run of an
experiment's `run.py` freezes its `PREREG.md` by hash (`.prereg.sha256`, committed); a later edit of
the file makes every later run refuse to start.*

## 0. Environment

Measured on: Windows 11, one NVIDIA RTX 4080 SUPER (16 GB), AMD Ryzen 7 7800X3D (8 cores),
Python 3.11.2, torch 2.7.1+cu118, transformers 4.57.6, datasets 4.0.0, tokenizers 0.22.2.
Installation: `pip install -e ".[dev,bench]"` and the CUDA build of torch for your platform.
`python -m pytest tests -q` must pass (129 tests; `tests/test_s2_probes.py` needs the GPT-2
tokenizer in the local Hugging Face cache, which `scripts/fetch_wikitext103.py` downloads once).

Data: `bash scripts/fetch_data.sh` (the small corpora and, if wanted, MaleCNS; checksums in
`data/SHA256SUMS`), `python scripts/fetch_wikitext103.py` and `python scripts/fetch_tinystories.py`
(manifests with token counts and hashes in `data/manifests/`). Nothing under `data/text/` is committed.

Commit hashes in per-run records refer to the development history, which is not part of the
published repository; `scripts/export_runs.py` then reports that it cannot re-check code identity,
and docs/history/README.md records the checks made before publication.

## 1. Rules of operation on a shared, single GPU (each one was learned the hard way)

- Start long jobs detached and hidden: `pwsh -NoProfile -File scripts/launch_detached.ps1 -Name <name>
  -Command "<script.py args>" [-Env "A=1;B=2"]`; the log is `logs/<name>.log`. A job started from a
  terminal or a session dies with it; a job with a visible console window dies when the window is closed.
- Stop a grid with an empty file named `STOP` in its experiment directory (it stops between runs);
  stop a prototype with `STOP` in `experiments/p3_s2_lm/prototype_runs/`. Never kill a process that is
  using the GPU: on this machine that reset the driver and crashed the other GPU job.
- Keep total GPU memory under about 14 GB (a spill into system memory makes the machine unusable).
  Each `run.py` records `gpu_peak_reserved_gb` per run.
- Training batches are generated by worker processes (`--data_workers`; 2 at T = 256, 5 at T = 1,024);
  the batches are identical for any number of workers.
- `--compile` compiles the per-chunk step (identical arithmetic; the recompile limit is raised
  automatically so that a grid of many configurations stays compiled).
- Several processes may share one grid with `--claim`; a final run without it collects everything.
- `scripts/wait_then_run.py --wait <file> [--remove <STOP file>] -- <script.py args>` starts one job
  when another has written its summary (used to resume rung 1 after rung 1b, unattended).

## 2. Rung 1 (v3): the history states on the two-store memory

```
python experiments/p3_s1_hybrid/run.py --smoke --device cuda                          # toy size, scratch dir
python experiments/p3_s1_hybrid/run.py --probe --compile --device cuda --seeds 0 --rates 0.15 --only state free   # real size, scratch dir
python experiments/p3_s1_hybrid/run.py --compile --device cuda --data_workers 2       # THE GRID (freezes PREREG.md): 95 runs, seeds 10-14
python experiments/p3_s1_hybrid/run.py --compile --device cuda --variant replication --seeds 20 21 22 23 24 25   # only if SUPPORTED
```
About 15-30 minutes per run alone on the GPU (the 95 runs took 33 GPU-hours, partly shared). Outputs: `SUMMARY.md`, `summary.json` (with the computed
verdict: conjuncts A, B, C), `runs/` (not committed), then `python scripts/export_runs.py p3_s1_hybrid`
(one row per run in `runs_table.csv`; checks one PREREG hash and identical code across the runs'
commits), `python scripts/plot_s1.py` (figures in `experiments/p3_s1_hybrid/figures/`) and
`python scripts/build_results.py` (RESULTS.md).

## 3. Rung 1b (v2): the Kenyon-cell address against Gated DeltaNet

```
python experiments/p3_s1b_sparse/diagnostics/task_load.py                             # the task's memory load (PREREG numbers)
python experiments/p3_s1b_sparse/diagnostics/pilot_gdn.py dense:64 sparse:64 dense:128 sparse:128   # the pilots (overrides: arm:P:key=value,...)
python experiments/p3_s1b_sparse/run.py --compile --device cuda --data_workers 5       # THE GRID: 100 runs, seeds 10-14, P = 32/64/128
python scripts/export_runs.py p3_s1b_sparse && python scripts/plot_s1b.py && python scripts/build_results.py
```
5-6 minutes per run at P = 32, 10-25 at P = 64, 15-75 at P = 128 alone on the GPU (the 256-cell arms
are the slow ones). Figures in `experiments/p3_s1b_sparse/figures/`.

## 4. Exploratory language-model prototypes (not pre-registered)

```
python experiments/p3_s2_lm/probes.py --split validation && python experiments/p3_s2_lm/probes.py --split test   # D1-regime probes
python experiments/p3_s2_lm/prototype.py --corpus wikitext103 --arm dense  --seed 0 --steps 3000 --compile --checkpoint
python experiments/p3_s2_lm/prototype.py --corpus wikitext103 --arm sparse --seed 0 --steps 3000 --compile --checkpoint
python experiments/p3_s2_lm/prototype.py --corpus tinystories --arm dense --steps 3000 --B 4 --accum 4 --T 1024 --window 256 --compile --checkpoint --eval_windows 600
python experiments/p3_s2_lm/diagnose.py --run experiments/p3_s2_lm/prototype_runs/dense_s1          # ablations and gate statistics
python experiments/p3_s2_lm/sample.py --run experiments/p3_s2_lm/prototype_runs/tinystories_dense_s0 --prompt "Once upon a time" --n 3
```
Set `HF_HUB_OFFLINE=1` after the first tokenizer download. Micro-batches of 2 x 2,048 tokens with
4-fold gradient accumulation and activation checkpointing (4.3-4.5 GB); 80-340 minutes per run
depending on the arm and on what else shares the GPU. Results: `prototype_runs/<run>/metrics.json`,
`diagnostics.json`, `samples.txt` (committed; weights are not).

## 6. Rung 2 (a pre-registered language-model test) was not run

Its rules were fixed before the rung-1 and rung-1b verdicts (EXPERIMENT_PLAN.md, "Rung 2: how its
arms follow from rungs 1 and 1b"): it was reserved for a mechanism those rungs supported, and
neither was. The exploratory prototypes above are not that test and are labelled accordingly.
